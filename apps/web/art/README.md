# Christmas illustration

`christmas-scene.svg` is original artwork created for this app. It depicts a snowy Christmas house, gifts, and a small Nativity with Mary, Joseph, the infant Jesus, and the Star of Bethlehem. `sleigh.svg`, `chimney-smoke.svg`, and `window-lights.svg` are aligned decorative layers in the same 760 × 570 coordinate system. CSS animates the layers automatically and disables every effect for system reduced motion. None of the artwork contains invitation data.

The cosy holiday-house direction is inspired by the atmosphere of Christmas films, including Home Alone. No film stills, music, logos, characters, or source artwork are included. All shapes are local SVG; no remote images, fonts, or dependencies are needed. Keep it in the service worker allowlist and bump the cache version when it changes.

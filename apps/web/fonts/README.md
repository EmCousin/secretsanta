# Festive type

`BerkshireSwash-Regular.ttf` is the unmodified Berkshire Swash Regular font by Brian J. Bonislawsky / Astigmatic, distributed under the SIL Open Font License 1.1 in `OFL.txt`.

Pinned source: `google/fonts` commit `db548d2df61806b37598a2d6839040866c2d6ae2`, `ofl/berkshireswash/BerkshireSwash-Regular.ttf`.

Upstream font blob: `0b673f442bdb6faacc40de90f36808a38acd2b08` (58,400 bytes).

Use the calligraphic face for display headings, the wordmark, and primary buttons. Form fields and supporting text keep system fonts for readability. The app serves this font locally, with a serif fallback and `font-display: swap`; it makes no Google Fonts request. The complete font is cached for offline use, including French and Brazilian Portuguese accents. No conversion, subsetting, or build step is required.
